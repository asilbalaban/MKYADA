# MKYADA display font — drawn for this project, no third-party font inside.
#
# Box is 5x8. Rows 0-6 are the glyph body (cap height 7, x-height 5 starting at
# row 2); row 7 is the descender row, used only by g j p q y and the comma.
# Glyphs are drawn LEFT-ALIGNED and the compiler derives each one's advance
# from its rightmost lit column + a 1px gap — that is what makes the font
# proportional, so 'i' costs 2px where 'W' costs 6.
#
# Compile:  node scripts/build-font.mjs --preview
# The preview PNGs (atlas + 128x64 screen proofs) land next to this file and
# are the only sane way to judge a change. Edit, recompile, look.

name mkyada
box 5 8
first 0x20

# --- beyond ASCII ---
# Everything past this point is looked up through the .fnt's extras table
# rather than by subtraction, so the codepoints can be the real ones and do
# not have to be contiguous.

# Turkish. The keypad is used in Turkish, and at 5x8 these cost 12 glyphs —
# about 150 bytes of atlas — so folding them to ASCII was only ever worth it
# back when a Turkish glyph meant a lazily-rasterized BDF on a fragmented heap.
# Accented capitals lose a row off the top to make room for the mark; the
# cedilla hangs into the descender row.
